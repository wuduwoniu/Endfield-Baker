# 庄方宜模拟器 V1.00 项目简介

## 线上地址
**https://deepseek-chat-clone.vercel.app**

---

## 一、项目概述

基于 React 19 + Vite 8 构建的 AI 多角色聊天应用，模拟《明日方舟：终末地》角色对话。采用 Baker-DX 暗色工业风格 UI（背景色 `#0a0b10`），通过 DeepSeek API 驱动角色扮演对话。

### 核心体验
- 选择不同角色开启对话，每个角色有独立人设
- AI 流式回复（逐字输出），支持 Markdown 渲染
- 38 个表情包系统，点击发送表情，AI 理解情绪含义
- Baker 风格 UI 完美还原（聊天头、装饰边框、头像框、SVG 尾巴）

---

## 二、技术架构

### 四层架构（单向依赖）

```
components/hooks  →  store  →  api  →  config
                    store  →  utils
                    api    →  config
```

| 层级 | 目录 | 职责 | 依赖 |
|------|------|------|------|
| 配置层 | `src/config/` | API 地址、模型定义、UI 文本、表情映射 | 零依赖 |
| 通信层 | `src/api/` | 封装 DeepSeek API 调用和 SSE 流解析 | 只依赖 config |
| 工具层 | `src/utils/` | 纯函数：ID 生成、时间格式化、文本截断 | 零依赖 |
| 状态层 | `src/store/` | Zustand 管理聊天状态、角色人设、流式控制 | 依赖 api + utils |
| UI 层 | `src/components/` | 所有界面组件 | 主要通过 store selector 获取数据 |
| Hooks | `src/hooks/` | 主题切换 Hook | 独立 |

### 组件数据获取规范

- **运行时状态**（消息列表、流式状态等）→ 必须通过 store selector
- **静态常量**（UI 文本、表情映射表等）→ 允许直接从 config import
- **禁止** 组件直接 import api/ 或 utils/

---

## 三、安全架构

API Key 永不进入前端 bundle：

```
开发环境              Vite proxy (loadEnv) 注入 Key → 代理到 DeepSeek API
生产环境 (Vercel)     Serverless Function (api/deepseek.js) 注入 Key → 转发 DeepSeek API
前端发请求            fetch /api/deepseek/chat/completions（无 Authorization header）
```

## 四、功能模块

### 4.1 多角色系统

三名可对话角色，侧边栏点击切换：

切换角色时自动清空消息并注入对应人设提示词（system message）。

### 4.2 表情包系统

**入口**：输入框右侧表情按钮（`chat_emoji.png`）

**弹窗**：
- 底部居中弹出，输入栏正上方
- 8 列网格，2 行可见，上下滑动浏览 38 个表情
- 灰色背景 `rgb(220,220,220)`，每个表情在白色圆角方格中展示
- 点击遮罩关闭

**发送机制**：
- 用户点击表情 → 输入框插入 `[情绪]` 中文标记（如 `[开心]`、`[愤怒]`）
- 发送后 AI 收到情绪文字，理解表情含义
- 聊天记录中 `[情绪]` 自动渲染为对应表情图片（用户看到图像）

**38 个表情**：开心、星星眼、惊讶、微笑、点赞、难过、大笑、哭泣、无语、流汗、酷、咧嘴笑、困惑、沉思、祈祷、OK、吐舌头、爱心、害羞、笑喷、比心、闪光、尴尬笑、开心笑、+1、怀疑、满分、躺倒、愤怒、恼怒、晕眩、震惊、担心、睡觉、可疑、静音、碰拳、思考

### 4.3 流式对话

- SSE 流式传输，AI 逐字输出
- 消息气泡支持 Markdown（react-markdown + GFM + 代码高亮）
- 流式进行中有闪烁光标指示
- 可随时停止流式生成

### 4.4 聊天头切换

ChatHeader 提供两套 Baker 风格聊天头装饰（Default / Alt），通过菜单按钮切换，默认使用 Alt 版。

### 4.5 主题切换

支持深色/浅色模式，状态持久化到 localStorage，通过 Header 中的日月图标切换。

### 4.6 新会话

侧边栏底部"添加新会话"按钮，一键清空当前对话。

## 六、Zustand 状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `messages` | `Array<{id, role, content, timestamp}>` | 消息列表 |
| `currentMode` | `string` | 当前模型模式 (fast/expert/vision) |
| `currentPrompt` | `string \| null` | 当前角色人设提示词 |
| `isStreaming` | `boolean` | 是否流式传输中 |
| `error` | `string \| null` | 错误信息 |
| `abortController` | `AbortController \| null` | 流式中断控制器 |

**Actions**：`sendMessage()`、`setMode()`、`setPrompt()`、`clearMessages()`、`stopStream()`、`appendChunk()`、`finishStream()`

---

## 七、数据流（发送消息）

```
用户输入文字 → ChatInput.handleSend()
  → 首次消息时 store.setPrompt(character.prompt)      # 注入角色人设
  → store.sendMessage(text)
    → 过滤空占位消息，构建 historyMessages
    → 若有 currentPrompt，插入 system message
    → api.sendChatMessage(historyMessages)
      → POST /api/deepseek/chat/completions
      → 【本地】Vite proxy 注入 Key
      → 【线上】Vercel Serverless 注入 Key
    → parseSSEStream(response.body)                   # 逐 chunk 解析
    → store.appendChunk() → finishStream()
    → MessageBubble 实时显示 AI 回复
```
