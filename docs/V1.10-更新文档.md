# V1.10 更新文档

## 更新日期
2026-05-05

## 更新概述
在 V1.00 基础上新增 168 张表情贴图系统，支持 Emoji/贴图双标签切换面板，贴图可独立发送或与文字混合发送。

---

## 新增功能

### 1. 表情贴图系统

**双标签面板**：
- StickerPanel（原名 EmojiPanel）新增左侧竖排双标签切换
- Emoji 标签：保持原有 38 个表情，8 列网格
- 贴图标签：新增 168 张贴图，5 列网格，2 行可见，可滚动

**贴图素材**：
- 源：`public/baker-assets/baker-dx-master/assets/extracted/sticker/`
- 搬迁到：`public/baker-assets/stickers/`
- 统一命名：`game/sticker_game_001~120.png` + `skland/sticker_skland_001~048.webp`

**发送逻辑**：

| 场景 | 行为 |
|------|------|
| 输入框空 + 选贴图 | 面板关闭，贴图立即发出，AI 回复随机贴图 |
| 有文字 + 选贴图 | 面板关闭，贴图加入队列，输入框显示缩略图（可 × 删除） |
| 发送文字+贴图 | 先发文字 → 逐张发贴图 → 最后触发 AI 回复 |
| 纯贴图发送 | 逐张发贴图 → AI 回复随机贴图 |

**贴图消息气泡**：
- 120×120 大图显示
- 保留用户气泡背景 + 头像框
- 无 SVG 尾巴
- 支持用户和 AI 双方贴图

**键盘交互**：
- 所有面板按钮使用 `onMouseDown + preventDefault`，点击为唯一选择方式
- 面板打开时按 Enter → 关闭面板 + 发送文字
- 面板关闭后输入框自动恢复聚焦

### 2. AI 贴图回复

纯贴图消息（无文字）发送后，AI 随机从 168 张贴图中选一张回复，延迟 500ms。

### 3. 贴图过滤

贴图消息不传给 AI（过滤 `contentType === 'sticker'`），避免 AI 困惑。

## 技术要点

- 贴图队列 `stickerQueue` 为 ChatInput 本地 state，不写入 store
- `sendSticker` 和 `sendStickerReply` 是 store 同步 action，不调 API
- `addUserText` + `triggerAiReply` 替代了原 `sendMessage` 的部分职责，用于文字+贴图混合场景
- 贴图消息 `contentType: 'sticker'` 在构建 AI history 时被过滤（两处：`sendMessage` 和 `triggerAiReply`）
- 面板按钮用 `onMouseDown` + `e.preventDefault()` 阻止键盘聚焦
